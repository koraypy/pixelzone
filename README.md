# Minik Oda — Pixel World

Tarayıcı tabanlı, tek sayfalık izometrik pixel-art oda prototipi.

## Çalıştırma
`index.html` dosyasını bir web sunucusunda açın. GitHub Pages üzerinde yayınlamak için:

1. GitHub'da yeni bir **Public** repository oluşturun (ör. `minik-oda`).
2. Bu klasördeki dosyaların tamamını repository'nin kök dizinine yükleyin.
3. Repository → **Settings → Pages** bölümüne gidin.
4. **Deploy from a branch** seçin.
5. Branch olarak `main`, klasör olarak `/(root)` seçip **Save** deyin.
6. Birkaç dakika sonra GitHub Pages size `https://KULLANICI-ADIN.github.io/minik-oda/` biçiminde bir adres verir.
