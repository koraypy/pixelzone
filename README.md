# Taht Salonu — Karakter İzleyici

İzometrik salonda karakterlerin rastgele dolaştığı, tarayıcıda çalışan statik proje.

## GitHub Pages
Dosyaları bir repo köküne yükle → Settings → Pages → Deploy from a branch → `main` / `(root)`.
Yerelde denemek için `python3 -m http.server` ile aç (`file://` ile characters.json okunamaz).

## Karakterler
- **Dosyadan:** `characters.json` + `assets/characters/` (ayrıntı: `assets/characters/README.txt`)
- **Hazır karakterler:** `builtin-characters.js` — dosyayı silersen kalkar.
